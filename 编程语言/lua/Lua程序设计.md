
# 入门

- `lua -i prog`：执行完程序 prog 之后进入交互模式。
- `dofile("main.lua")`：在交互模式下执行这个函数，会加载 main.lua 这个程序。
- 单行注释：`--`
- 多行注释：`--[[  ]]`，取消多行注释直接在前面加 `-`。
- `type()`：获取一个值对应的类型名称。
- 只有 boolean 的 false 和 nil 表示逻辑的假，其余任何值在条件判断中都是真。
- `and` 如果第一个操作数为假，则返回第一个操作数。
- `or` 如果第一个操作数为真，则返回第一个操作数。、
- `lua -e`：直接在命令行输入代码。
