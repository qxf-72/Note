本仓库主要用于备份个人学习笔记。

笔记以 Markdown 格式编写，其中使用了：

- Markdown 扩展语法
- LaTeX 公式
- HTML 语法

部分编辑器可能无法完整渲染。图床使用 Obsidian + PicGo + 阿里云 OSS 搭建；笔记使用 Obsidian 编辑，插件、主题等相关配置文件位于 `.obsidian` 目录。
